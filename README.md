# Salut 10 - treningsrom

Digital treningsressurs i fransk for 10. trinn.

Første versjon inneholder:

- lys og visuell forside
- Modul 1: Verbverksted
- 30 verboppgaver totalt
- nivåvalg: blandet, lett, middels og utfordring
- repetisjon av -ER, -IR og -RE-verb
- repetisjon av être og avoir
- poeng og fremgang
- rett/galt-tilbakemelding
- regel og hint som eleven kan åpne selv
- opplesing av franske eksempelsetninger
- opptak, ny innspilling og avspilling av egen stemme

Planlagte moduler:

- Modul 2: eiendomsord
- Modul 3: passé composé med avoir og être
- c'est / il y a
- tall, årstall og ordenstall
- flere oppgaver knyttet til franske byer og regioner
