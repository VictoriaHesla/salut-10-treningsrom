# Salut 10 - treningsrom

Digital treningsressurs i fransk for 10. trinn.

Første versjon inneholder:

- lys og visuell forside
- moduloversikt
- verbverksted med repetisjon av -ER, -IR og -RE-verb
- repetisjon av être og avoir
- poeng og fremgang som lagres i nettleseren
- rett/galt-tilbakemelding med korte tips
- opplesing av fransk eksempelsetning
- opptak og avspilling av egen stemme

Planlagte moduler:

- eiendomsord: mon, ma, mes, ton, ta, tes osv.
- passé composé med avoir
- passé composé med être
- c'est / il y a
- tall, årstall og ordenstall
- flere oppgaver knyttet til franske byer og regioner
